# 📅 Расписание НГУЭУ — Группа 9-ИС403

Минималистичный автономный фронтенд для просмотра учебного расписания Новосибирского государственного университета экономики и управления (НГУЭУ). Сайт автоматически забирает данные с официального сервера вуза, фильтрует их и выводит в удобном виде.

## 🚀 Реальные возможности

* **Полный офлайн-режим (PWA):** Сайт работает как веб-приложение. Его можно установить на рабочий стол компьютера или экран смартфона. Благодаря сервис-воркеру расписание открывается мгновенно даже при полном отсутствии интернета.
* **Приватная аналитика кнопок:** В код встроен нейтральный счетчик GoatCounter. Он фиксирует общую посещаемость, типы устройств, а также клики по кнопкам («Подгруппа 1/2», «1/2 неделя», «Сегодня», «Обновить»), позволяя видеть, какими фильтрами одногруппники пользуются чаще всего. При этом сервис не собирает IP-адреса и куки.
* **Серверная независимость:** Приложение полностью клиентское. Вся верстка, стили, логика парсинга официального расписания и счетчики умещаются в одном файле `index.html`.

## 📁 Структура файлов в корне

* `index.html` — интерфейс, парсер данных с `rasps.nsuem.ru`, стили, трекер кнопок и регистрация приложения.
* `site.webmanifest` — манифест с настройками PWA (название, цвета и пути к иконкам).
* `sw.js` — сервис-воркер для кэширования страницы `index.html` и работы сайта в офлайне.
* `android-chrome-192x192.png` & `android-chrome-512x512.png` — адаптивные иконки приложения с буквами «ИС».
* `apple-touch-icon.png` — иконка для экранов устройств Apple.
* `favicon.ico`, `favicon-16x16.png`, `favicon-32x32.png` — иконки для вкладок браузера.

## ⚙️ Запуск и деплой

Проект полностью готов для бесплатного размещения на **Vercel**. Для локального тестирования достаточно открыть `index.html` в браузере (желательно через локальный сервер, например, расширение Live Server в VS Code, чтобы браузер не блокировал внешние запросы Fetch к сайту вуза).
